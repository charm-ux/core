# A11Y-011: Make closed or off-screen content `inert`

Content that is closed/hidden but still in the DOM — a collapsed disclosure body, a closed
push-pane, a dismissed overlay — must be removed from the tab order **and** the accessibility
tree. Mark it `inert` when closed instead of relying on `hidden`/`display:none` alone, because
those don't guarantee the subtree is unfocusable in every assistive tech. Bind `inert`
reactively to the `open` state and cover the transition with a test.

**Do:**

```ts
// disclosure.ts / push-pane.ts
protected render() {
  return html`
    <div class="panel" part="panel" ?inert=${!this.open} aria-hidden=${!this.open}>
      <slot></slot>
    </div>
  `;
}
```

**Don't:**

```ts
// Closed but still focusable and announced — Tab can land inside the hidden panel.
<div class="panel" hidden><slot></slot></div>
```
