# A11Y-013: Label every field in composite form controls

When a form control is composed from multiple native fields, give the group a relationship to
the visible field label and give every native field its own localized accessible name. Do not
use `aria-valuetext` on ordinary text inputs; it is not an allowed attribute for the textbox
role. If the component uses a visually hidden native input for form association, expose the
visible field through a `validationAnchor` hook so browser validation never points at hidden
content.

For popup editors, name the dialog, focus its content on open, and restore focus after keyboard
dismissal. Outside-pointer dismissal must leave focus at the user's clicked destination. Keep
unfinished selections as drafts until the user's action commits them; cancel must preserve the
previous form value.

**Do:**

```ts
return html`
  <div role="group" aria-labelledby="date-label">
    <label class="visually-hidden" for="date-month"><slot name="month-label">Month</slot></label>
    <input id="date-month" type="text" />
  </div>
`;
```

**Don't:**

```ts
// The visible label names only the first field; the others are unlabeled or English-only.
<label for="month">Date</label>
<input id="month" aria-valuetext="August" />
<input id="day" />
<input id="year" />
```
