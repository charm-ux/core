# A11Y-006: Return focus to the opener when a dismissible closes

When an overlay/dismissible opens, capture the element that had focus (the trigger/anchor, or
`activeElement` at open time); when it closes, move focus back to it. Without this, keyboard
and screen-reader users are dropped at the top of the document after closing a menu, dialog,
tooltip, or alert.

**Do:**

```ts
// alert.ts
public override show() {
  this.originalTrigger = this.findRootNode(this)?.activeElement as HTMLElement | null;
  super.show();
  this.messageContent?.focus();
}

public override hide() {
  if (!this.open) return;
  if (this.originalTrigger && typeof this.originalTrigger.focus === 'function') {
    this.originalTrigger.focus();
  }
  return super.hide();
}

// menu.ts — restore to the trigger on close
protected requestClose(source: MenuCloseSource) {
  if (this.emitRequestClose(source).defaultPrevented) return;
  this.trigger?.focus();
}
```

**Don't:**

```ts
// Closes without restoring focus — the user loses their place in the tab order.
public hide() {
  this.open = false;
}
```
