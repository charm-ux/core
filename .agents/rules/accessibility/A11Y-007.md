# A11Y-007: Use roving tabindex for composite widgets

Composite widgets where arrow keys move between items (menu, tabs, radio-group, button-group)
expose exactly one tab stop: the active item has `tabindex="0"`, all others `tabindex="-1"`.
Track the active index in a field, and on arrow/Home/End navigation set the outgoing item to
`-1`, the incoming item to `0`, and call `.focus()` on it. Keep the field in sync when focus
moves by other means (e.g. click) via the item `focus` handler.

**Do:**

```ts
// menu.ts
protected setFocus(targetIndex: number) {
  this.items[this.focusIndex].setAttribute('tabindex', '-1');
  this.focusIndex = clampIndex(targetIndex, this.items.length);
  const next = this.items[this.focusIndex];
  next.setAttribute('tabindex', '0');
  next.focus();
}

protected handleItemFocus = (e: FocusEvent) => {
  const target = e.target as HTMLElement;
  if (!this.items?.length || target === this.items[this.focusIndex]) return;
  this.items[this.focusIndex].setAttribute('tabindex', '-1');
  this.focusIndex = this.items.indexOf(target);
  target.setAttribute('tabindex', '0');
};
```

**Don't:**

```ts
// Every item is a tab stop — the user must Tab through all of them instead of arrowing.
this.items.forEach(item => item.setAttribute('tabindex', '0'));
```
