# A11Y-008: Compare `event.key` against the shared `keys` map, not string literals

Keyboard handlers compare `event.key` to the named constants in the shared `keys` map
(`src/utilities/key-map.ts`), not to raw string literals. This avoids the easy-to-miss traps —
`Space` is `' '`, arrows are `'ArrowUp'` not `'Up'` — and keeps every keyboard handler in the
library consistent and greppable.

**Do:**

```ts
import { keys } from '../../utilities/key-map.js';

// tabs.ts
protected handleKeyDown(event: KeyboardEvent) {
  switch (event.key) {
    case keys.ArrowRight:
      this.focusNext();
      break;
    case keys.Home:
      this.focusFirst();
      break;
    case keys.Space:
    case keys.Enter:
      this.select();
      break;
  }
}
```

**Don't:**

```ts
// Magic strings: ' ' vs 'Space' and 'ArrowRight' vs 'Right' are easy to get wrong and drift.
if (event.key === 'ArrowRight') this.focusNext();
if (event.key === 'Space') this.select(); // wrong: the key is ' '
```
