# A11Y-012: Meet contrast for text and essential control boundaries

Text must meet WCAG contrast of 4.5:1 for normal-sized text (3:1 for large text). Placeholder
text is text and has the same requirement. Essential non-text UI boundaries and state indicators,
such as a text field's border against its background, must meet 3:1. Disabled-state exemptions
do not justify low contrast in an enabled state.

Use semantic theme tokens for borders and placeholder text, and verify both light and dark
themes. Do not assume a token named `neutral-300` or `placeholder` has sufficient contrast; check
its actual rendered color against the control background. Add contrast checks when changing
default theme values.

**Do:**

```ts
border-color: ${semantic('formControl', 'borderColor')};
color: ${semantic('formControl', 'placeholderColor')};
```

**Don't:**

```ts
/* Use a low-contrast default border just because it looks subtle on white. */
border-color: ${semantic('defaultBorder', 'color')};
```
