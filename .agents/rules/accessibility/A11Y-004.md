# A11Y-004: Ship an accessibility test for every component

Accessibility is verified, not assumed. The shared base harness
(`CharmElementTests`) runs an `accessibility` test that asserts
`await expect(el).to.be.accessible()` (axe-based) against every component — so every
component that runs the base harness gets baseline coverage for free
([TEST-001](../testing/TEST-001.md)). Keep that coverage:

- Don't skip or delete the base accessibility test.
- If a component needs axe rule exceptions, scope them narrowly with `ignoredRules` and
  justify them — don't disable the whole check.
- Add component-specific a11y assertions (focus order, `aria-expanded` toggling, live
  regions) on top of the baseline.
- Test the component in a realistic semantic parent when its role depends on composition
  (for example, a breadcrumb item inside a labeled navigation/list).
- Every accessibility test must make an assertion. Do not leave placeholder or empty test
  functions, even when axe requires a parent fixture.

**Do:**

```ts
// Base harness assertion (already provided) — keep it running.
await expect(this.component).to.be.accessible({
  ignoredRules: ['aria-allowed-role'], // narrow, justified exception
});
```

**Don't:**

```ts
// Empty tests create false coverage without exercising an accessibility assertion.
it('is accessible', async () => {});
```
