# A11Y-002: Use DOM text for user-facing accessible names

Always provide a user-facing accessible name as real DOM text inside the control or through an
appropriate labeling relationship. If the text should not be visible, apply the `visually-hidden`
utility class to that text. Do not set `aria-label` for user-facing copy, even alongside DOM text:
it can override the translatable name. DOM text can be translated by browser and consumer
translation tools ([I18N-001](../i18n/I18N-001.md)); an `aria-label` string cannot reliably be
translated. If the text is not a descendant of the named control, use `aria-labelledby` to
reference its DOM text in the same tree scope. The `visually-hidden` class ships from the base
styles ([STYLE-003](../styling/STYLE-003.md)); toggle it with `classMap`.

An icon-only visual control still needs translated DOM text inside the button/link (for example,
a visually-hidden close-button label). `CoreIcon.label` names the icon itself as an image; it is
not a substitute for the enclosing control's text label.

**Do:**

```ts
protected radioLabelTemplate() {
  return html`<span
    part="radio-label"
    class=${classMap({ 'radio-label': true, 'visually-hidden': this.hideLabel ?? false })}
  >
    ${this.label ? html`${this.label}` : html`<slot></slot>`}
  </span>`;
}
```

```ts
// An icon is decorative here; the hidden text names the button itself.
html`
  <button>
    <scoped-icon name="dismiss"></scoped-icon>
    <span class="visually-hidden">${this.closeButtonLabel}</span>
  </button>
`;
```

**Don't:**

```ts
// aria-label is an attribute, not translatable DOM text.
return html`
  <span aria-label="Select this option"></span>
`;

// Don't rely on an image's label as the control's only user-facing name.
html`
  <button><scoped-icon name="dismiss" label=${this.closeButtonLabel}></scoped-icon></button>
`;
```
