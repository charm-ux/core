# I18N-002: Support RTL through direction-aware styling and behavior

Components must work in right-to-left locales. The base class already handles `dir`
propagation; your job is to make layout and interaction direction-aware:

- Style with CSS logical properties, never physical left/right
  ([STYLE-004](../styling/STYLE-004.md)).
- For directional keyboard interaction (arrow-key navigation in composite widgets), respect
  the resolved direction so ArrowRight/ArrowLeft mean "next/previous" correctly in RTL.
- Verify RTL visually — Storybook has `storybook-addon-rtl`, so add/keep an RTL view for
  components with meaningful directional layout ([DOC-001](../documentation/DOC-001.md)).

**Do:**

```ts
export default css`
  .list {
    display: flex;
    gap: 0.5rem;
    padding-inline-start: 1rem; /* flips automatically in RTL */
  }
`;
```

**Don't:**

```ts
export default css`
  .list {
    padding-left: 16px; /* stuck on the left even in RTL */
    margin-right: 8px;
  }
`;
```

See also: [STYLE-004](../styling/STYLE-004.md), [I18N-001](./I18N-001.md), [DOC-001](../documentation/DOC-001.md)
