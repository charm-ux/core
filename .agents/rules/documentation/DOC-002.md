# DOC-002: Scaffold new components with plop

Create new components with the plop generator (`pnpm plop` → "Core component") rather than
copying files by hand. The generator produces the full canonical file set into
`packages/core/src/components/<name>/`, wires the barrel export, and adds the docs page — so
every component starts consistent with the conventions in these rules.

The generated file set:

| File                     | Purpose                                    | Rule                                                                         |
| ------------------------ | ------------------------------------------ | ---------------------------------------------------------------------------- |
| `<name>.ts`              | Component class (`Core<Name>`, `baseName`) | [CHARM-001](../internal/CHARM-001.md), [CHARM-002](../internal/CHARM-002.md) |
| `<name>.styles.ts`       | Lit `css` styles                           | [STYLE-001](../styling/STYLE-001.md)                                         |
| `index.ts`               | Scope registration                         | [CHARM-002](../internal/CHARM-002.md)                                        |
| `<name>.test.ts`         | Harness entry                              | [TEST-001](../testing/TEST-001.md)                                           |
| `<name>.test-harness.ts` | Reusable test suite                        | [TEST-001](../testing/TEST-001.md)                                           |
| `<name>.html.stories.ts` | Storybook stories                          | [DOC-001](./DOC-001.md)                                                      |
| `<name>.performance.ts`  | Performance test                           | —                                                                            |
| `<name>.mdx` (in docs)   | Docs page                                  | —                                                                            |

It also appends `export * from './<name>/<name>.js';` to `packages/core/src/components/index.ts`.

**Do:**

```bash
pnpm plop            # choose "Core component", enter a kebab-case name
```

**Don't:**

- Copy another component's folder and rename files — you'll miss the barrel export and docs
  wiring and drift from the template.
- Hand-create a partial file set (e.g. skip the test-harness or the story).

See also: [TEST-001](../testing/TEST-001.md), [DOC-001](./DOC-001.md), [CHARM-002](../internal/CHARM-002.md)
