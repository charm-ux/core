# I18N — Internationalization

Internationalization rules. Full details in [`.agents/rules/i18n/`](../../.agents/rules/i18n/).

- **I18N-001** — Render user-facing text via slots/DOM (consumer-translatable), never hardcode display strings into the component. ([details](../../.agents/rules/i18n/I18N-001.md))
- **I18N-002** — Support RTL: logical properties in CSS, direction-aware keyboard nav, and an RTL Storybook view (`storybook-addon-rtl`). ([details](../../.agents/rules/i18n/I18N-002.md))
