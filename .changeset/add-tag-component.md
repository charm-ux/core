Add the `ch-tag` component: a compact, focusable label with optional remove button (`removable`), `disabled` and `selected` states, a `value`, a translatable `remove-label` slot, and a cancelable `tag-remove` event triggered by the remove button or the Delete/Backspace keys. Adds `tag` tokens to the charm theme.
