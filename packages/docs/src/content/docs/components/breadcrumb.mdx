A breadcrumb component is a navigational tool displayed on a website or a web application, showing the hierarchical path to the current page. It enables users to understand their location within the site's structure and easily navigate back to previous pages.

## Basic breadcrumb

Use `<ch-breadcrumb-item>` as links within the opening and closing of the `<ch-breadcrumb>` element.

<code-bubble>

```html
<ch-breadcrumb label="Product hierarchy">
  <ch-breadcrumb-item>Catalog</ch-breadcrumb-item>
  <ch-breadcrumb-item>Clothing</ch-breadcrumb-item>
  <ch-breadcrumb-item>Men's</ch-breadcrumb-item>
  <ch-breadcrumb-item>Suits</ch-breadcrumb-item>
</ch-breadcrumb>
```

</code-bubble>

## Custom separator

By default, a chevron separates the items and mirrors in `rtl`. Set the `separator` slot on `<ch-breadcrumb>` to replace it. The separator is placed between every item and mirrors in `rtl` like the default.

<code-bubble>

```html
<ch-breadcrumb label="Product hierarchy">
  <span slot="separator">/</span>
  <ch-breadcrumb-item>Catalog</ch-breadcrumb-item>
  <ch-breadcrumb-item>Clothing</ch-breadcrumb-item>
  <ch-breadcrumb-item>Men's</ch-breadcrumb-item>
  <ch-breadcrumb-item>Suits</ch-breadcrumb-item>
</ch-breadcrumb>
```

</code-bubble>

## Accessibility

Every breadcrumb must have a localized `label` attribute. It sets the accessible name of the navigation landmark and is announced by screen readers.

<code-bubble>

```html
<ch-breadcrumb label="Breadcrumb for catalogs">
  <ch-breadcrumb-item>Catalog</ch-breadcrumb-item>
  <ch-breadcrumb-item>Clothing</ch-breadcrumb-item>
  <ch-breadcrumb-item>Men's</ch-breadcrumb-item>
  <ch-breadcrumb-item>Suits</ch-breadcrumb-item>
</ch-breadcrumb>
```

</code-bubble>
