# Button Group

Button groups can be used to group related buttons into sections.

## Basic button group

<code-bubble class="not-content">

```html
<ch-button-group>
  <ch-button>Left</ch-button>
  <ch-button>Center</ch-button>
  <ch-button>Right</ch-button>
</ch-button-group>
```

</code-bubble>

## Accessible name

Use the `label` property for a plain-text accessible name, or the `label` slot for rich or localized content. The group references the rendered label text with `aria-labelledby`.

<code-bubble class="not-content">

```html
<ch-button-group label="Text formatting options">
  <ch-button>Bold</ch-button>
  <ch-button>Italic</ch-button>
  <ch-button>Underline</ch-button>
</ch-button-group>
```

</code-bubble>

<code-bubble class="not-content">

```html
<ch-button-group>
  <span slot="label">Text formatting options</span>
  <ch-button>Bold</ch-button>
  <ch-button>Italic</ch-button>
  <ch-button>Underline</ch-button>
</ch-button-group>
```

</code-bubble>

## Dropdowns in button groups

Dropdowns can be placed inside button groups as long as the trigger is a `<ch-button>` element.

<code-bubble class="not-content">

```html
<ch-button-group>
  <ch-button>Button</ch-button>
  <ch-button>Button</ch-button>
  <ch-menu style="--popup-z-index: 1;">
    <ch-button slot="trigger">Dropdown</ch-button>
    <ch-menu-item>Item 1</ch-menu-item>
    <ch-menu-item>Item 2</ch-menu-item>
    <ch-menu-item>Item 3</ch-menu-item>
  </ch-menu>
</ch-button-group>
```

</code-bubble>

## Vertical button groups

The `vertical` attribute can be used to create a vertical button group.

<code-bubble class="not-content">

```html
<ch-button-group vertical>
  <ch-button>Button</ch-button>
  <ch-button>Button</ch-button>
  <ch-menu style="--popup-z-index: 1;">
    <ch-button slot="trigger">Dropdown</ch-button>
    <ch-menu-item>Item 1</ch-menu-item>
    <ch-menu-item>Item 2</ch-menu-item>
    <ch-menu-item>Item 3</ch-menu-item>
  </ch-menu>
</ch-button-group>
```

</code-bubble>

## Split button groups

The `split` attribute can be used to create a split button group, styled as a single button with multiple actions.

<code-bubble class="not-content">

```html
<ch-button-group split>
  <ch-button>Button</ch-button>
  <ch-button>Button</ch-button>
  <ch-menu style="--popup-z-index: 1;">
    <ch-button slot="trigger">Dropdown</ch-button>
    <ch-menu-item>Item 1</ch-menu-item>
    <ch-menu-item>Item 2</ch-menu-item>
    <ch-menu-item>Item 3</ch-menu-item>
  </ch-menu>
</ch-button-group>
```

</code-bubble>

## Toolbar button groups

The `toolbar` attribute makes the button group a toolbar and enables arrow-key navigation with a roving tab index. Give each toolbar an accessible name with `label` or the `label` slot.

<code-bubble class="not-content">

```html
<ch-button-group toolbar label="Document formatting">
  <ch-button>Button</ch-button>
  <ch-button>Button</ch-button>
  <ch-button>Button</ch-button>
</ch-button-group>
```

</code-bubble>

## Common scenarios

### Text formatting toolbar

Use toggle buttons for formatting states and a divider to separate action groups.

<code-bubble class="not-content">

```html
<ch-button-group toolbar label="Document formatting">
  <ch-button toggle>Bold</ch-button>
  <ch-button toggle>Italic</ch-button>
  <ch-button toggle>Underline</ch-button>
  <ch-divider></ch-divider>
  <ch-button>Align left</ch-button>
  <ch-button>Align center</ch-button>
  <ch-button>Align right</ch-button>
</ch-button-group>
```

</code-bubble>

### View-mode selector

Use `select="single"` for mutually exclusive options. The active option can be toggled off, so the group may have no selection.

<code-bubble class="not-content">

```html
<ch-button-group select="single" label="View mode">
  <ch-button pressed>List</ch-button>
  <ch-button>Board</ch-button>
  <ch-button>Calendar</ch-button>
</ch-button-group>
```

</code-bubble>

### Navigation links

Use links when each action navigates to another location, and name the group for assistive technology.

<code-bubble class="not-content">

```html
<ch-button-group label="Primary navigation">
  <ch-button href="/dashboard" current="page">Dashboard</ch-button>
  <ch-button href="/projects">Projects</ch-button>
  <ch-button href="/reports">Reports</ch-button>
</ch-button-group>
```

</code-bubble>

## Button group with select

The `select` attribute can be set to "single" to allow the selection of a single button, or "multiple" for multiple selections. When buttons in a button group with the `select` attribute are toggled, the button group emits a `change` event.

<code-bubble class="not-content">

```html
<ch-button-group
  select="single"
  style="--charm-button-pressed-bg-color: var(--charm-button-active-bg-color);"
>
  <ch-button>Select Single</ch-button>
  <ch-button>Select Single</ch-button>
  <ch-button>Select Single</ch-button>
</ch-button-group>
```

</code-bubble>

<code-bubble class="not-content">

```html
<ch-button-group
  select="multiple"
  style="--charm-button-pressed-bg-color: var(--charm-button-active-bg-color);"
>
  <ch-button>Select Multiple</ch-button>
  <ch-button>Select Multiple</ch-button>
  <ch-button>Select Multiple</ch-button>
</ch-button-group>
```

</code-bubble>
