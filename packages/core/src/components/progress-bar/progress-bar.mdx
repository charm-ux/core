# Progress Bar

Add examples and descriptions of the component features here.

## Default

<code-bubble>

```html
<ch-progress-bar value="70"></ch-progress-bar>
```

</code-bubble>

## Indeterminate

Use the `indeterminate` attribute to show indeterminate progress.

<code-bubble>

```html
<ch-progress-bar label="Indeterminate Progress Bar" indeterminate></ch-progress-bar>
```

</code-bubble>

## Setting a custom height

Use the `--charm-progress-bar-height` css property to set a custom height.

<code-bubble>

```html
<ch-progress-bar
  label="Custom Height Progress Bar"
  value="70"
  style="--charm-progress-bar-height: 20px;"
></ch-progress-bar>
```

</code-bubble>
