# Icon

Icons are symbols that can be used to represent various options within an application.

## Selecting the Icon

Icons are selected based on the value passed to the `name` attribute.

<code-bubble>

```html
<ch-icon name="warning"></ch-icon>
```

</code-bubble>

## Providing a Label

Icons are hidden from assistive technologies by default. When an icon carries meaning, use `label` so the text is rendered in the accessibility tree as translatable DOM text instead of an attribute value.

<code-bubble>

```html
<ch-button>
  <ch-icon name="dismiss" label="close the dialog"></ch-icon>
</ch-button>
```

</code-bubble>

## Using an External Icon

Sometimes you may need to access external icons that are self-hosted or from a CDN. Use the `url` property without the `name` attribute. If the `name` attribute is used, it will be used instead of the `url`.

External SVG content is parsed as a DOM node before insertion, which avoids executing inline event handlers or script-like content from untrusted SVG sources.

<code-bubble>

```html
<ch-icon url="https://api.iconify.design/fluent:chat-12-filled.svg"></ch-icon>
```

</code-bubble>

## Rotating and Flipping

Icons support `rotate` and `flip` properties for simple transform adjustments.

<code-bubble>

```html
<ch-icon name="warning" rotate="90" flip="both"></ch-icon>
```

</code-bubble>

## Fallback Icon

If an icon is not found because the `name` does not match one of the defined icons or the `url` fetch fails, the component falls back to the default question icon. The fallback is the bundled `question` icon unless you override it with a custom SVG string.

## Styling Icons

Icons should inherit most of their styles including size and color and can be customized using standard CSS.

<code-bubble>

```html
<ch-icon name="warning" style="color: red; font-size: 5rem; rotate: 90deg;"></ch-icon>
```

</code-bubble>
