# Disclosure

The disclosure component is used for creating expandable and collapsible sections in a web page or application.

## Default

Put an actual button in the `trigger` slot (it may be wrapped in a heading); the content region uses the default slot. The button receives `aria-expanded` as the disclosure opens and closes.

<code-bubble>

```html
<ch-disclosure>
  <h3 slot="trigger"><button>Heading</button></h3>
  Content region
</ch-disclosure>
```

</code-bubble>

## Open

The content region is expanded by setting the `open` attribute in the `<ch-disclosure>` element

<code-bubble>

```html
<ch-disclosure open>
  <h3 slot="trigger"><button>Heading</button></h3>
  Content region
</ch-disclosure>
```

</code-bubble>

## Open direction

By default, the content region expands upwards. To modify the expansion direction to downwards, add the `content-below` attribute to the `<ch-disclosure>` element.

<code-bubble>

```html
<ch-disclosure content-below>
  <h3 slot="trigger"><button>Heading</button></h3>
  Content region
</ch-disclosure>
```

</code-bubble>

## Preview Mode

The disclosure component can show a preview of the content when closed by setting the `--charm-disclosure-closed-max-height` CSS custom property to a value other than `0px` (the default).

<code-bubble>

```html
<style>
  .disclosure-preview {
    --charm-disclosure-closed-max-height: 4rem;
    --charm-disclosure-gap: 8px;
  }
  .disclosure-button,
  .disclosure-button:hover {
    color: var(--body-fg-color);
    background-color: transparent;
    border: none;
    box-shadow: none;
  }
  .disclosure-button:focus-visible {
    outline: 2px solid currentColor;
    outline-offset: 2px;
  }
  ch-disclosure[open] .chevron {
    transform: rotate(-180deg);
  }
</style>
<div class="disclosure-preview" style="max-width: 600px;">
  <ch-disclosure>
    <button slot="trigger" class="disclosure-button">
      <ch-icon slot="start" class="chevron" name="chevron-down"></ch-icon>
      <span class="button-text">Show More</span>
    </button>
    This is a disclosure with --charm-disclosure-closed-max-height set to a non-zero value. When
    closed, only a few lines of this text will be shown due to the max-height constraint. When open,
    all of the content will become visible. You can use this to create collapsible previews for long
    sections of content without hiding them entirely. Lorem ipsum dolor sit amet, consectetur

  <script>
```

## Transition

The disclosure component supports smooth open/close animations using CSS transitions. Enable animations by setting the `--charm-disclosure-show-transition` and/or `--charm-disclosure-hide-transition` custom CSS properties.

<code-bubble>

```html

    --charm-disclosure-closed-max-height: 4rem;
    --charm-disclosure-gap: 8px;
    --charm-disclosure-show-transition: max-height 0.5s ease-in-out;
    --charm-disclosure-hide-transition: max-height 0.5s ease-in-out;
  }
  .disclosure-button,
  .disclosure-button:hover {
    color: var(--body-fg-color);
```
